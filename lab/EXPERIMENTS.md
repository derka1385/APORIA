2026-10-04, first v2 runs (qwen2.5:3b, Δ = 1, architecture condition):

- Different policies did produce different research processes. In run 034623 the skeptic
  proposed 5 hypotheses and rejected 4 after 2 defeating tests, while the formalist kept
  its first hypothesis, spent 20% of compute on formal checks and stopped after 8 steps.
  Compute allocation by function differs visibly across profiles in every run.
- Conclusions converge more than processes: conclusion similarity 0.71-0.97 while path
  similarity stays 0.31-0.42. The small model pulls final positions toward "qualified".
- Long-term memory homogenised the reasoners. In run 040020 every profile recalled the
  same earlier conclusions and objections (5-12 recalls each) and four of five ended
  "qualified 0.70-0.75". Fix: memory is now scoped per profile (only the synthesizer reads
  everyone's), and runs can turn memory off so Δ comparisons stay independent of run order.
- Failure: the conclusion prompt's placeholder "one or two sentences" was copied as the
  position. Fixed by moving the instruction out of the JSON schema and stripping echoes.
- Failure: evidence strength counted unverified premises, so the "uncertain and
  under-evidenced" signal never fired and memory was never chosen; the weak-assumption
  signal re-fired after the assumption was already tested, so counterfactuals crowded out
  doubt. Both fixed (premises weigh 0.15 until verified; tested assumptions stop signalling;
  new "no objection raised yet" signal).
- Failure: runs 035110 and 035122 hit Ollama 500s while it restarted; every reasoner died.
  LLM and embedding calls now retry with backoff and a failed call costs one step.
- Thermal: five parallel reasoners overheated the laptop. Reasoners now take turns (one
  model call at a time), rest 0.5 s per call, and "quick" mode halves the budget.

batch plan were stopped for heat before they ran.

Experimental research lab · Hack-Nation Challenge 3 · Agentic scientific discovery

Same model. Same question. Five ways of thinking.

Agent swarms built on one LLM tend to reason alike. APORIA externalizes the cognitive functions around the model: metacognition, curiosity, counterfactual tests, adversarial experiments, memory and formal tools. It then turns one parameter, Δ, to differentiate how five reasoners use those functions, and measures how differently they actually reasoned.

Research question

Can explicit cognitive functions, orchestrated around one LLM, produce genuinely different reasoning?

Most AI labs scale the number of agents. APORIA treats how an agent thinks as the experimental variable. Every reasoner gets the same question, the same model and the same tools. What differs is its cognitive policy: which operations its controller favours, how far its attention explores, how much evidence it needs before it accepts a claim, how hard it attacks, when it stops.

Hypothesis: Δ ↑ → reasoning-path diversity ↑ → argument diversity ↑ → unique objections ↑ → possibly different conclusions.

Philosophy is the test domain because a dialectical stress test needs no wet lab. An objection, a counterexample and a failed defence are already the experiment.

Method

One engine, five policies, one dial.

Each reasoner holds a typed argument graph (hypotheses, premises, assumptions, objections, counterexamples, counterfactuals, evidence, questions) and runs this loop until it concludes or runs out of budget:

metacognition reads the graph "confident but weakly supported" → doubt "rests on a weak assumption" → counterfactual "unresolved contradiction" → adjudicate "not formally checked" → formalize (truth table) controller: drive(op) = (state + signals) × policy weight × learned value attention: branch ~ softmax(curiosity / explore) operation: one LLM call and/or a tool edits the graph learning: information gain → op value, branch yield
  1. Policy vectors, not personas. A profile sets about twenty real parameters: operation weights, controller and attention temperatures, sampling, context visibility, literature and memory access, tool access, objections per doubt, adversarial damage, acceptance, rejection and stopping thresholds, budget.
  2. Δ interpolates. param = base + Δ · (target − base). At Δ = 0 all five reasoners run the identical base policy and only seeds differ. That run is the noise floor.
  3. Four conditions. base identical policies; prompt identical policies plus a persona sentence; architecture Δ-scaled policies, no persona; model each reasoner on a different model.
  4. Measured, never rewarded. No reasoner is told to disagree. Path similarity is one minus the normalised edit distance of operation sequences. Branch diversity is the Jensen–Shannon distance of node-type distributions. Unique objections are those with no match at cosine ≥ 0.8 in any other reasoner. Conclusion similarity is the cosine of final positions.
  5. Live stream. Every cognitive event (attention, contradiction, rejection, insight, recall, tool call) streams over SSE to the lab UI and to a separate particle engine, whose form follows the real state.

Explorer

Imagination, intuition, counterfactuals, inquiry. High exploration and sampling temperature. No formal tools.

Formalist

Verification and formalization with every tool. Strict acceptance, near-greedy attention.

Skeptic

Doubt and adjudication. Four objections per doubt, 1.8× damage. Memory of past objections, no literature.

Synthesizer

Deliberately distant literature, wide context, fast learning, shared memory.

Minimalist

Introspection and formalization from at most two assumptions. Narrow context, no literature.

Next experiment · model-level differentiation

Compression as a cognitive intervention.

LobBot compresses a 30B mixture-of-experts teacher (Qwen3-30B-A3B, 61 GB) into a 6.5 GB model for one task. It prunes the experts the task does not route through (REAP), heals with LoRA distillation and quantizes per layer. On a support-ticket task it kept 0.974 of the teacher's 0.981 judge score.

APORIA can use that pipeline in a different way. If REAP is calibrated on a cognitive function's own traces (the skeptic's objections, the formalist's formalizations, the explorer's thought experiments), each profile keeps different experts. Five reasoners would then differ in their weights as well as in their policies. The model condition then compares structural differentiation against policy differentiation on the same base model.

Status: designed, not run. One LobBot job takes about 25 minutes on an evroc B200. TaskSpecs per profile are in lab/lobbot/. Until a run exists, the site reports no compression result.

Limits · read before trusting a number

What this does not show yet.

  1. Small n. One or two runs of five reasoners per condition. The full Δ sweep covers one question; the Δ 0 / Δ 1 comparison covers four. Differences are consistent in direction, not tested for significance.
  2. Conclusions converge. Conclusion similarity stays near 0.9 in every condition. Different processes have not yet produced different answers.
  3. Model judgements. Verdicts (valid, survives, damage) come from the same LLM. The truth-table check is real, but it only checks the model's own formalization.
  4. Small embedding model. Similarity uses nomic-embed-text. Absolute values are rough, so compare conditions against the base noise floor.
  5. Infrastructure failures are shown. A dropped tunnel to the VM produced empty runs. They are flagged and excluded, and the batch now stops when the endpoint is down.
